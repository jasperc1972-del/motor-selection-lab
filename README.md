# 馬達選型實驗室 Motor Selection Lab

馬達、齒輪、減速機選型的互動學習工具。拖動參數，就能看到扭矩、轉速、功率怎麼變；最後用輸送帶、升降機從頭實算一次選型。
整個工具寫在單一 `index.html` 裡（HTML + CSS + JavaScript），不需要安裝任何東西。

## ▶ 線上直接使用

**https://jasperc1972-del.github.io/motor-selection-lab/**

也可以下載這個專案（綠色 **Code** 按鈕 → **Download ZIP**），解壓縮後雙擊 `index.html`。

## 五個單元

| 單元 | 內容 |
|---|---|
| **1. 馬達基礎** | 扭矩、轉速、功率的關係。拖動工作轉速，看直流馬達的扭矩直線與功率曲線，理解 `P = T × n ÷ 9.55` |
| **2. 馬達種類** | 有刷直流、步進、伺服、感應＋變頻器的特性曲線、原理、優缺點、使用時機，附比較表與選擇流程 |
| **3. 齒輪基礎** | 模數、齒數、中心距、減速比、效率、背隙。齒輪咬合動畫即時更新；往復模式可看到換向時背隙造成的空轉 |
| **4. 選型計算器** | 輸送帶／升降機選型實算：10 步逐步計算、馬達特性曲線上的需求點、扭矩／轉速／慣量比檢查、自動選型 |
| **5. 選型挑戰** | 12 題情境選擇題，每題附解說 |

## 選型計算器的計算流程

1. 負載端轉速 `n = v ÷ (π × D)`
2. 運轉阻力（輸送帶 `F = m·g·(μ·cosθ + sinθ)`；升降機 `F = (載重 + 車廂 − 配重)·g`）
3. 負載端扭矩 `T = F × D/2`
4. 減速比與馬達轉速 `n馬達 = n × i`
5. 馬達端運轉扭矩 `T ÷ (i × η)`
6. 負載慣量 `J = m × r²`，換算到馬達端 `J ÷ i²`
7. 加速扭矩 `(J負載/η + J馬達) × α`
8. 乘安全係數，得到連續扭矩與峰值扭矩
9. 運轉功率 `P = T × n ÷ 9.55`
10. 慣量比檢查

檢查標準：

| 馬達 | 檢查項目 |
|---|---|
| 伺服 | 連續扭矩 ≤ 額定曲線、峰值扭矩 ≤ 最大扭矩曲線、慣量比 ≤ 10（≤ 30 可接受） |
| 步進 | 峰值需求 ≤ 脫出扭矩的 70%、慣量比 ≤ 10 |
| 感應＋變頻 | 連續扭矩 ≤ 額定曲線、啟動扭矩 ≤ 150%、慣量比 ≤ 30 |

> 內建馬達規格為**示意值**，數量級接近市售產品，用於學習。實際選型請以原廠型錄為準，並視需要補算有效（RMS）扭矩、再生能量等項目。

## 給開發者

`index.html` 分成三塊，程式碼都有繁體中文註解：

- `<style>`：外觀與配色（顏色變數集中在 `:root`）
- `<body>`：分頁與各單元的版面
- `<script>`：
  - **選型計算**（`LOGIC-START` ~ `LOGIC-END` 之間）：馬達資料 `MOTORS`、特性曲線 `curve()`、負載計算 `calcLoad()`、馬達端計算與檢查 `calcMotor()`、自動選型 `autoSelect()`。不碰畫面，可以單獨測試
  - **畫面**：通用圖表 `plot()`、齒輪繪製 `drawGear()`、各單元的更新函式

### 新增馬達型號
在 `MOTORS` 對應類別加一筆，例如伺服：

```js
{ name: '伺服 3kW', P: 3000, Tr: 9.55, Tp: 28.6, nr: 3000, nmax: 4500, J: 7.0 * KGCM2 },
```

| 欄位 | 意義 |
|---|---|
| `Tr` / `Tp` | 伺服額定扭矩／最大扭矩（N·m） |
| `Th` / `nc` | 步進保持扭矩（N·m）／扭矩降到一半的轉速（rpm） |
| `nr` / `nb` / `nmax` | 額定轉速／基底轉速／最高轉速（rpm） |
| `J` | 轉子慣量（kg·m²，用 `數值 * KGCM2` 從 kg·cm² 換算） |

### 新增題目
在 `QUIZ` 陣列加一筆：`{ q: 題目, opts: [四個選項], a: 正確答案索引, exp: 解說 }`。
